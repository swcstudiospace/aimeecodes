# CI/CD

GitHub Actions for Aimee Codes. Source of truth for **what runs today** is the committed YAML under `aimeecodes/.github/workflows/`. Source of truth for **what should be generated next** is `crates/aimee_ci`. This page documents both and calls out drift. It does not claim green CI or invent release URLs.

Live remote: [swcstudiospace/omegaloops](https://github.com/swcstudiospace/omegaloops). Workflow badge in the README points at that repo's `ci.yml` (`README.md:30`).

## Generated workflows — do not hand-edit

Every committed workflow starts with the same warning (`aimeecodes/.github/workflows/ci.yml:1-16` and the same header on the others):

- Generated by `gh-workflows` using the `gh-workflow-gen` bin.
- **Do not edit the YAML by hand.** Manual changes are lost on regenerate.
- Change the Rust description, then regenerate.

In this tree that description lives in `crates/aimee_ci`, not in `crates/aimee_main/build.rs` (that file only injects `APP_VERSION` / `CARGO_PKG_NAME` — `crates/aimee_main/build.rs:6-22`). The crate is the workspace member `aimee_ci` (`README.md:347`, `crates/aimee_ci/Cargo.toml:1-15`). It depends on `gh-workflow` (`Cargo.toml:49`, `crates/aimee_ci/Cargo.toml:10`).

Public generators (`crates/aimee_ci/src/workflows/mod.rs:1-19`):

| Function | Output file |
|---|---|
| `generate_ci_workflow` | `ci.yml` |
| `generate_autofix_workflow` | `autofix.yml` |
| `generate_bounty_workflow` | `bounty.yml` |
| `generate_coderabbit_workflow` | `coderabbit.yml` |
| `generate_labels_workflow` | `labels.yml` |
| `generate_release_drafter_workflow` | `release-drafter.yml` |
| `release_publish` | `release.yml` |
| `generate_stale_workflow` | `stale.yml` |

Regenerate by running the crate tests. Each test calls one generator (`crates/aimee_ci/tests/ci.rs:3-41`):

```bash
cargo test -p aimee_ci
```

That **rewrites** `.github/workflows/*.yml`. Review the diff before committing. Prefer editing `crates/aimee_ci` (jobs, matrix, steps) over the generated YAML.

## `RUSTFLAGS=-D warnings`

CI and autofix deny Rust warnings at the workflow env level:

- `ci.yml` sets `RUSTFLAGS: '-Dwarnings'` (`aimeecodes/.github/workflows/ci.yml:19-20`). Generator: `RustFlags::deny("warnings")` (`crates/aimee_ci/src/workflows/ci.rs:70`).
- `autofix.yml` sets the same (`aimeecodes/.github/workflows/autofix.yml:19-20`; `crates/aimee_ci/src/workflows/autofix.rs:44`).

Clippy steps also pass `-- -D warnings` (`aimeecodes/.github/workflows/autofix.yml:55`; `crates/aimee_ci/src/jobs/lint.rs:42`).

`README.md:364`: CI sets `RUSTFLAGS=-D warnings`. Match that locally:

```bash
RUSTFLAGS='-D warnings' cargo test --workspace --all-features
```

## Workflows

### `ci.yml` — name `ci`

Triggers (`aimeecodes/.github/workflows/ci.yml:22-35`): pull_request to `main` (`opened`, `synchronize`, `reopened`, `labeled`); push to `main` and tags `v*`.

Concurrency group `${{ github.workflow }}-${{ github.ref }}` (`aimeecodes/.github/workflows/ci.yml:295-296`). Default cancel-in-progress is unset (do not assume it cancels).

Also injects `OPENROUTER_API_KEY: ${{secrets.OPENROUTER_API_KEY}}` as a workflow env (`aimeecodes/.github/workflows/ci.yml:21`). Do not print or commit that value.

| Job | When | What it actually runs |
|---|---|---|
| `build` (`Build and Test`) | every matching event | checkout, `arduino/setup-protoc@v3`, `actions-rust-lang/setup-rust-toolchain@v1` with `toolchain: stable`, `cargo install cargo-llvm-cov`, then `cargo llvm-cov --all-features --workspace --lcov --output-path lcov.info` (`aimeecodes/.github/workflows/ci.yml:37-56`). Contents: read. |
| `zsh_rprompt_perf` | every matching event | same checkout / protoc / stable toolchain, then `./scripts/benchmark.sh --threshold 60 zsh rprompt` (`aimeecodes/.github/workflows/ci.yml:57-74`). |
| `draft_release` | `push` to `refs/heads/main` only, after `build` | `release-drafter/release-drafter@v7` with `config-name: release-drafter.yml`; exports `crate_release_id` and `crate_release_name` (`aimeecodes/.github/workflows/ci.yml:75-99`). |
| `draft_release_pr` | PR labeled `ci: build all targets` | writes `pr-build-${{ github.event.number }}` as the version/id (`aimeecodes/.github/workflows/ci.yml:100-112`). |
| `build_release` | `push` to `main`, after `draft_release` | 9-target matrix (see below); uploads each binary to the draft release (`aimeecodes/.github/workflows/ci.yml:113-207`). |
| `build_release_pr` | PR labeled `ci: build all targets` | same matrix; `APP_VERSION` is the PR build name. The committed YAML for this job has **no** copy/upload steps (`aimeecodes/.github/workflows/ci.yml:208-294`). |

The `build` job does **not** run `cargo test` as a separate step. Coverage is `cargo llvm-cov --all-features --workspace`. It does not upload `lcov.info` in the committed YAML.

`zsh_rprompt_perf` builds `target/debug/aimee` via `scripts/benchmark.sh` (which runs `cargo build`), then times `target/debug/aimee zsh rprompt` ten times and fails if the average exceeds 60 ms (`scripts/benchmark.sh:22-45`, `scripts/benchmark.sh:121-127`).

### `autofix.yml` — name `autofix.ci`

Triggers: PR to `main` (`opened` / `synchronize` / `reopened`) and push to `main` (`aimeecodes/.github/workflows/autofix.yml:21-31`). Concurrency `autofix-${{github.ref}}`, `cancel-in-progress: false` (`aimeecodes/.github/workflows/autofix.yml:60-62`).

Single job `lint` (`Lint Fix`), contents: read (`aimeecodes/.github/workflows/autofix.yml:33-59`):

1. checkout
2. `sudo apt-get install -y libsqlite3-dev`
3. `arduino/setup-protoc@v3`
4. nightly toolchain with `clippy, rustfmt`
5. `cargo +nightly fmt --all` (fix mode — no `--check`)
6. `cargo +nightly clippy --all-features --workspace --all-targets --fix --allow-dirty -- -D warnings`
7. `cargo +nightly clippy --all-features --workspace -- -D clippy::string_slice -D clippy::indexing_slicing -D clippy::disallowed_methods` (no `--fix`)
8. `autofix-ci/action@7a166d7532b277f34e16238930461bf77f9d7ed8` (digest-pinned)

String-safety clippy matches `clippy.toml:1-3` (`std::string::String::from_utf8_lossy` is disallowed). Command builders: `crates/aimee_ci/src/jobs/lint.rs:24-67`.

## How to run locally what CI runs

From an `aimeecodes` checkout. CI's `build` job uses `toolchain: stable` plus `RUSTFLAGS=-D warnings`. A checkout also has `rust-toolchain.toml` pin `1.97`.

```bash
# Match ci.yml `build` (coverage over the workspace)
cargo install cargo-llvm-cov   # once
RUSTFLAGS='-D warnings' cargo llvm-cov --all-features --workspace --lcov --output-path lcov.info

# Match ci.yml `zsh_rprompt_perf`
./scripts/benchmark.sh --threshold 60 zsh rprompt

# Match autofix.yml lint (nightly; --fix mutates the tree)
cargo +nightly fmt --all
cargo +nightly clippy --all-features --workspace --all-targets --fix --allow-dirty -- -D warnings
cargo +nightly clippy --all-features --workspace -- -D clippy::string_slice -D clippy::indexing_slicing -D clippy::disallowed_methods

# Check-only (closer to a PR gate without autofix)
cargo +nightly fmt --all -- --check
cargo +nightly clippy --all-features --workspace --all-targets -- -D warnings

# README development slice (not the full CI matrix)
cargo fmt
cargo check -p aimee_main
cargo clippy -p aimee_main --all-targets -- -D warnings
cargo insta test --accept -p aimee_main

# Optional per-crate TDD gate (not a GitHub workflow)
./scripts/tdd-gate.sh aimee_domain

# Bounty TypeScript tests (package.json)
npm install
npm run test:bounty

# Regenerate workflows from aimee_ci (rewrites YAML)
cargo test -p aimee_ci
```

`insta.yaml` sets `auto_accept` / `auto_accept_unseen` and `runner: nextest` (`insta.yaml:1-4`). CI does not invoke `cargo insta` or `nextest` in the committed `ci.yml`.

Protobuf: local/Nix builds need `protoc` (`flake.nix:65`, `flake.nix:132`). CI non-cross jobs use `arduino/setup-protoc@v3` (`crates/aimee_ci/src/steps/setup_protoc.rs:7-10`).
