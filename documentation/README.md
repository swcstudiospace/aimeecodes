# Aimee Codes documentation

<p align="center"><strong>Sage researches. Muse plans. Aimee implements and verifies.</strong></p>

Aimee Codes is a WEB3-aware, terminal-native coding agent. Three cooperating agents — a **flock** — read your code, plan changes, implement them, and verify with real commands, from a ratatui TUI, a one-shot CLI, or a ZSH `:` prefix.
