FAQ

Frequently asked

What is Aimee Codes?

A Rust CLI / TUI coding agent with a built-in flock of specialists, slash commands, and prompt templates — packaged as aimee.

How is this like ClippyOS?

Same marketing posture and typeface family (IBM Plex Mono), sticky mono nav, product-shot sections, and clear CTAs — recolored to bubblegum pink for Aimee.

Which font should I use in the terminal?

JetBrains Mono (Warp default mono). The landing uses IBM Plex Mono for UI chrome to match ClippyOS; terminal screenshots use JetBrains Mono.

Where is the installable app?

The PWA shell lives at app.html. Install from Chrome/Edge/Safari after opening it over HTTPS or localhost.
